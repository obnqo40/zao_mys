Политика конфиденциальности

Страница описывает, как сайт обрабатывает обращения, отправленные через формы, `mailto`-ссылки и другие каналы связи.

1. Общие положения

Сайт создан для информирования о деятельности ЗАО «МЫС», продукции, новостях и способах связи с компанией. При отправке обращения пользователь добровольно передаёт данные, необходимые для обратной связи по его запросу.

2. Какие данные могут обрабатываться

При обращении через сайт могут использоваться имя, адрес электронной почты, название компании или проекта, а также текст сообщения. Эти данные применяются только для обработки запроса, подготовки ответа и последующей деловой коммуникации по теме обращения.

3. Цель обработки

Данные используются для связи с потенциальными и действующими клиентами, уточнения технических требований, подготовки коммерческих предложений, организации консультаций и ответа на входящие запросы.

4. Передача данных

Сайт не публикует переданные пользователем персональные данные в открытом доступе. Передача третьим лицам допускается только в объёме, необходимом для законной деловой переписки, технического сопровождения сайта или в случаях, предусмотренных законодательством.

5. Контакты

По вопросам, связанным с обращениями через сайт, можно связаться с компанией по адресу `info@mpsplastik.ru` или по телефону `+7 (48432) 23-242`.
